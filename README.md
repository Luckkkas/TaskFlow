TaskFlow — Gerenciador de Tarefas

Organize suas tarefas, acompanhe seu progresso e mantenha sua rotina em ordem com o TaskFlow.

Sobre o projeto

O TaskFlow é uma aplicação web de gerenciamento de tarefas desenvolvida com HTML, CSS e JavaScript. O projeto foi criado para oferecer uma maneira simples e intuitiva de organizar atividades diárias, com foco em usabilidade, organização e interatividade.

Tecnologias utilizadas

- HTML5 — estrutura e organização do conteúdo.
- CSS3 — estilização e apresentação visual.
- JavaScript — lógica da aplicação e funcionalidades interativas.

Funcionalidades

- [x] Adicionar tarefas.
- [x] Visualizar tarefas cadastradas.
- [x] Marcar tarefas como concluídas.
- [x] Excluir tarefas.
- [x] Interface simples e intuitiva.
- [x] Interatividade com JavaScript.

Como executar o projeto

1. Clone o repositório:
   
   git clone https://github.com/Luckkkas/taskflow.git

2. Entre na pasta do projeto:
   
   cd taskflow

3. Abra o arquivo "index.html" no navegador.
